# Ambulant (2026 revival fork)

Ambulant Player: a SMIL 3.0 playback engine (C++ core plus Python bindings),
CWI's central multimedia software from 2003 to 2016. This repo is Jack's fork
(`origin` = `cwi-dis/ambulant-2026-jack`, `upstream` = `cwi-dis/ambulant`)
for an experiment to see whether it can be revived. Karthik does the same
experiment independently in his own fork.

## Where to look first

- `claude-notes/` — our working notes: architecture, history, rot audit.
  Start with `claude-notes/README.md`.
- `Documentation/Design/text/*.txt` — the original design documents (mostly
  last updated for 1.8, around 2007, but the structure still holds).
- `Documentation/Design/text/organisation.txt` — source code conventions.
  Follow them when editing (tabs, `m_` members, `snake_case`, `ambulant::`
  sub-namespaces, headers under `include/ambulant/...`).

## Layout in one breath

`include/ambulant/{lib,net,common,smil2,gui/*}` holds the headers, and
`src/libambulant/` the same structure for the implementation. Players are in
`src/player_*`, browser plugins in `src/npambulant` and `src/ieambulant`
(both dead technology), the Python bridge in `src/pyambulant` (generated by
`bgen`), and loadable plugins in `src/plugins`. Builds use autotools at the
top level, plus `projects/{xcode43,vc10,android}`.

## Rules for this repo

- Separate "make it build" commits from behavioural changes.
- Don't rewrite history. The git history is already lossy (tags and hg
  branch names were lost in conversions; see `claude-notes/history-cold.md`).
